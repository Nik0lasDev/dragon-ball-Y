# Dragon Ball: Ki Rising

Protótipo de jogo 2D em pixel art, executado diretamente no navegador. Esta primeira versão concentra-se no combate básico, no gerenciamento de Ki e no treinamento.

## Como jogar

Abra [https://nik0lasdev.github.io/dragon-ball-Y/](https://nik0lasdev.github.io/dragon-ball-Y/) depois de habilitar o GitHub Pages para publicar a branch `main` pela opção **Deploy from a branch** (pasta `/root`).

Também é possível testar localmente: baixe o repositório e abra `index.html` em um navegador moderno. Não há dependências ou etapa de build.

## Controles

| Tecla | Ação |
|---|---|
| A / D ou ← / → | Mover |
| W ou ↑ | Pular |
| Shift | Correr |
| J (segurar) | Concentrar Ki |
| J (soltar) | Lançar a Bola de Ki |
| K | Ataque físico |
 
## Sistemas desta versão

- Barras de vida e Ki, com regeneração de energia.
- Bola de Ki carregável: segurar J consome energia e aumenta o tamanho e o dano do disparo; soltar lança a esfera.
- Inimigo básico que persegue e ataca o jogador.
- Modo de treinamento com alvo de prática e regeneração de Ki acelerada.
- Experiência e progressão de nível, aumentando os atributos.
- Cenário, personagens e efeitos desenhados em pixel art via Canvas.

## Tecnologias

- HTML5
- CSS
- JavaScript (Canvas 2D)

Sem bibliotecas, imagens externas ou serviços de terceiros.

## Estado do projeto

Versão inicial de protótipo. Animações, colisões, balanceamento e conteúdo ainda serão expandidos. A direção visual é uma interpretação original em pixel art, inspirada no clima visual de *Dragon Ball Evolution*.
